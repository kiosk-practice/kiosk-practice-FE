# AI 키오스크 체험

스마트폰과 키오스크 조작이 익숙하지 않은 분을 위한 브라우저용 React 연습 서비스입니다. 메가커피 주문, 맥도날드 주문, CGV 영화 예매, 다이소 셀프계산대를 체험할 수 있습니다.

각 화면에서 도움말을 펼칠 수 있습니다. 모의 결제가 끝나면 선택 기록에 따른 AI 해설 예시를 한 항목씩 보고 해당 단계만 다시 연습할 수 있습니다. 메뉴 가격과 상영 정보는 연습용이며, 결제와 해설은 브라우저에서 실행됩니다.

```sh
npm ci
npm run dev
```

배포용 빌드는 `npm run build`로 생성하고, `npm run preview`로 확인합니다.
