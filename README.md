# AI 키오스크 체험

스마트폰과 키오스크 조작이 익숙하지 않은 분을 위한 브라우저용 React 연습 서비스입니다. 메가커피 주문, 맥도날드 주문, CGV 영화 예매, 다이소 셀프계산대를 체험할 수 있습니다.

각 화면에서 도움말을 펼칠 수 있습니다. 모의 결제가 끝나면 선택 기록에 따른 AI 해설 예시를 한 항목씩 보고 해당 단계만 다시 연습할 수 있습니다. 메뉴 가격과 상영 정보는 연습용이며, 결제와 해설은 브라우저에서 실행됩니다.

```sh
npm ci
npm run dev
```

배포용 빌드는 `npm run build`로 생성하고, `npm run preview`로 확인합니다.

## 카페·다이소 연습

홈 → 체험 시작하기 → 카페 주문 또는 마트 셀프계산대에서 실행합니다.

- 카페: 메뉴 분류/페이지, 온도 선택, 수량, 장바구니 추가·수정·삭제, 결제 방법, 주문 확인, 해설 및 완료 화면
- 다이소: 상품 버튼으로 스캔 시뮬레이션 → 실제 목록 비교 → 수세미 3개를 2개로 수정 → 봉투 선택 → 카드 결제 연습 → 해설 및 완료
- 수세미 2개(각 1,000원), 테이프 1개(2,000원), 건전지 1개(1,000원)이며 소형 봉투를 선택하면 합계 5,100원입니다.
- DB, 백엔드, 결제 API, AI API를 사용하지 않습니다. 상태는 React 메모리에만 저장하며 새로고침·처음으로·다시 연습하기 시 초기화됩니다.
- 첨부 시안의 색상, 세로형 구성, 큰 버튼과 단계별 화면을 반영했습니다. 상품과 단말기는 외부 이미지 요청 없이 CSS/문자로 표현한 연습용 일러스트입니다. 가격은 연습용입니다.

검증: `npm test` (장바구니 병합·온도별 분리·합계·중복 수정·봉투 금액), `npm run build`.
